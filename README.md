# Hēi Kè (HK) Security Framework

Hēi Kè (黑客), meaning "dark guest" or hacker, is a Ruby-based security framework designed for modularity and ease of use. It will provide various tools for security testing, including:

*   Port Scanning
*   Web Application Analysis (crawling, vulnerability scanning)
*   Subdomain Enumeration
*   A flexible template engine for defining custom security checks (YAML and Ruby DSL)
*   Command-Line Interface (CLI)
